# Como contribuir

Contribuições didáticas são bem-vindas, especialmente melhorias de acessibilidade, documentação e compatibilidade entre navegadores.

1. Crie uma branch a partir de `main`.
2. Faça alterações pequenas e com objetivo claro.
3. Teste os dois idiomas, navegação por teclado e versões mobile/desktop.
4. Abra um pull request explicando o problema, a solução e como você verificou o resultado.

Não inclua dados pessoais, imagens de terceiros ou dependências sem necessidade.
